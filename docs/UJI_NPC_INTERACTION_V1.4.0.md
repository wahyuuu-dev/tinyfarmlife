# Laporan Implementasi — NPC Interaction V1.4.0 (Tahap 3)

## Fitur yang ditambahkan

- Mira memiliki sapaan dan tiga topik percakapan: pasar, kehidupan desa, dan tips berkebun.
- Bima memiliki sapaan dan tiga topik percakapan: aktivitas harian, arah Home Farm, dan kehidupan desa.
- Setiap topik menampilkan jawaban dan tombol untuk kembali ke daftar pertanyaan.
- Dialog dapat ditutup dengan tombol khusus, Escape, atau klik latar panel.
- Mode dialog menonaktifkan sementara input gerak dan update simulasi, lalu mengembalikan permainan setelah dialog ditutup.

## Cara mencoba

1. Jalankan proyek melalui Live Server.
2. Mulai permainan dan dekati Mira atau Bima di Greenfield Village.
3. Pastikan penanda aksi menampilkan nama NPC.
4. Tekan Space / Enter / F atau tombol AKSI.
5. Pilih topik, kembali ke daftar topik, lalu tutup percakapan.
6. Pastikan karakter dan jam permainan kembali berjalan setelah panel ditutup.
