# Checklist Pengujian Tiny Farm Life V1.1.0

Centang setelah benar-benar diuji. Jangan menandai lulus hanya berdasarkan pemeriksaan kode.

## Persiapan
- [ ] Ekstrak ZIP ke folder baru, jangan menimpa V1.0.0.
- [ ] Jalankan melalui Live Server.
- [ ] Buka DevTools Console dan pastikan tidak ada error awal.

## Tutorial
- [ ] Tutorial muncul saat Game Baru.
- [ ] Bergerak menyelesaikan langkah pertama.
- [ ] Mencangkul, menanam, menyiram, dan memanen memajukan langkah sesuai urutan.
- [ ] Membuka kios menyelesaikan langkah terakhir.
- [ ] Tombol Lewati panduan berfungsi.
- [ ] Reload / lanjutkan tidak menyebabkan error.

## Ringkasan harian
- [ ] Tanah dicangkul dihitung satu kali per aksi berhasil.
- [ ] Benih ditanam dihitung satu kali per aksi berhasil.
- [ ] Penyiraman dihitung satu kali per aksi berhasil.
- [ ] Panen dihitung satu kali per aksi berhasil.
- [ ] Pembelian dan penjualan menghitung jumlah serta nominal yang benar.
- [ ] Ringkasan muncul setelah hari selesai.
- [ ] Tombol Lanjutkan menutup ringkasan dan permainan berlanjut.
- [ ] Hari ke-20 tetap menampilkan Game Over sesuai aturan lama.

## Toko dan tanaman
- [ ] Waktu tumbuh sesuai data tanaman.
- [ ] Harga jual sesuai data tanaman.
- [ ] Daisy ditandai dekoratif.
- [ ] Beli/jual tetap memengaruhi koin dan inventory dengan benar.

## Kompatibilitas save dan regresi
- [ ] Save dari V1.0.0 dapat dilanjutkan.
- [ ] Data statistik dan tutorial tersimpan setelah save.
- [ ] Backup lama tetap dapat dipulihkan.
- [ ] Gerak, tabrakan, kamera, pertanian, Harmony, energi, waktu, kemenangan, dan kekalahan tetap berfungsi.

## PC
- [ ] Chrome
- [ ] Edge
- [ ] Firefox
- [ ] Resize jendela tidak memotong UI.

## Mobile
- [ ] Android Chrome, landscape
- [ ] iPhone Safari, landscape (jika tersedia)
- [ ] Joystick dan tombol aksi tidak tertutup panel tutorial.
- [ ] Ringkasan dapat dibaca dan digulir bila layar pendek.
- [ ] Rotasi layar tidak merusak tampilan.


## Catatan hasil pengujian pengguna
Pengguna melaporkan bahwa setelah mencoba paket V1.1.0, tidak menemukan bug. Platform, ukuran layar, browser, dan cakupan setiap skenario belum dirinci, sehingga checklist di atas tetap disediakan untuk verifikasi yang lebih menyeluruh.
