# Daftar Uji Tiny Farm Life V1.4.0

Dokumen ini adalah daftar pemeriksaan manual. Kotak yang belum dicentang belum dinyatakan lulus.

## Tahap 1 — Foundation Refinement

- [ ] Dialog Mira tampil utuh dan terbaca pada desktop.
- [ ] Dialog Mira tampil utuh dan terbaca pada HP landscape.
- [ ] Dialog Bima tetap berfungsi.
- [ ] Navigasi/aksi dialog tidak menutupi kontrol utama.
- [ ] Dekorasi slot 5–8 berada di area taman, bukan petak tanaman.
- [ ] Dekorasi tidak bertumpuk dengan pohon, bangunan, atau dekorasi lain.
- [ ] Posisi dekorasi tetap sama setelah simpan dan muat ulang.
- [ ] NPC Mira dan Bima tetap terlihat di Greenfield Village.
- [ ] Jalan dan kolam tetap terpisah.
- [ ] Malam terlihat pada pukul 18.00 dan 19.00.
- [ ] Tab Toko Benih dan Dekorasi & Upgrade berfungsi.
- [ ] Tidak ada tombol atau panel tutorial aktif.

## Tahap 2–7 — Village & NPC Life

- [ ] NPC mengikuti jadwal harian dan tidak menembus penghalang.
- [ ] Dialog NPC berubah sesuai waktu/perkembangan permainan.
- [ ] Aktivitas desa tidak menghambat navigasi/performa.
- [ ] Quest dapat diterima, diproses, diserahkan, dan diberi hadiah.
- [ ] Pesanan dan transaksi warga menggunakan saldo koin yang sama.
- [ ] Transaksi tidak dapat digandakan atau dilakukan tanpa syarat.
- [ ] Status quest, transaksi, dan area terbuka tersimpan.
- [ ] Pembukaan wilayah mengikuti syarat eksplorasi, quest, dan koin.

## Perangkat dan teknis

- [ ] Console browser bersih dari error.
- [ ] Keyboard desktop berfungsi.
- [ ] Kontrol sentuh HP berfungsi.
- [ ] Layout responsif pada HP dan laptop.
- [ ] Save lama dimigrasikan tanpa kehilangan item/dekorasi.
- [ ] ZIP dapat diekstrak dan dijalankan melalui server lokal.
